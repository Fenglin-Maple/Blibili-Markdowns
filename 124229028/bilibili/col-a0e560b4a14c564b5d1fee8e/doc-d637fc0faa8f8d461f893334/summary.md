本视频时长 93 秒，属于快速操作提示。它没有连续展示 API Key 创建表单、密钥粘贴界面、账单配置和最终登录成功后的完整验证，因此实际操作时仍应以 Codex 与 OpenAI 平台当时的页面规则、服务地区和计费政策为准。

- 使用前应确认 API 账户的账单、用量与预算控制设置。

这些安全提醒属于通用凭据管理建议，并非 UP 主在视频中的逐字内容。
